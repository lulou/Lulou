Voice notes are now FUNCTIONALLY WORKING in production.

Confirmed:

- voice notes send successfully

DO NOT TOUCH OR REWRITE THE WORKING VOICE-NOTE BACKEND / STORAGE / TRANSCODE / REALTIME / PLAYBACK PIPELINE.

I want the experience to feel much closer to the quality level of premium iOS social/messaging apps such as Snapchat, Instagram, Hinge and iMessage — without copying any one app pixel-for-pixel.

==================================================

Current bubbles are too large and too Android-like.

Replace them with a compact premium layout:

3. OUTGOING VOICE NOTE
==================================================

Outgoing voice notes should use the existing approved Lulou wine message family.

Use:

- elegant muted wine fill
- subtle contrast between played/unplayed waveform
- white/ivory play icon
- small readable duration
- restrained shadow/border only if already consistent with chat

==================================================
4. INCOMING VOICE NOTE
==================================================

Incoming voice notes should use:

- warm ivory / soft neutral surface
- wine accent for played progress
- dark taupe/wine iconography
- same geometry as outgoing bubble

Incoming and outgoing notes should clearly belong to the same design system.

==================================================
5. PLAY / PAUSE CONTROL
==================================================

The play/pause control should be compact.

Idle:
- small circular play icon

Playing:
- same control changes to pause

Do not use a huge coloured circle.

Touch target may remain ~44px while visual icon stays smaller.

==================================================
6. PREMIUM WAVEFORM
==================================================

The waveform needs to look refined.

Use:

- thin rounded vertical bars
- varied bar heights
- tight but breathable spacing
- smooth progression
- subtle contrast

Avoid:

- square bars
- dashed lines
- chunky segments
- equal-height mechanical bars
- giant waveform spanning the entire bubble

If current real waveform data is available, use it.

If not, continue using deterministic waveform generation but make the rendering visually refined.

==================================================
7. PLAYBACK PROGRESS
==================================================

As the note plays:

played portion:
- approved Lulou accent / brighter contrast

unplayed portion:
- muted lower-contrast version

Progress should move smoothly across the waveform.

No giant progress bar underneath.

==================================================
8. DURATION
==================================================

Show duration elegantly, e.g.:

0:05
0:21
1:03

Use small iOS-like secondary typography.

Keep it aligned cleanly to the waveform/play control.

Do not make duration visually dominant.

- same overall visual family as normal composer
- compact height
- smooth transition
- live timer
- subtle live waveform/activity
- clear cancel

- no giant mic circle
- no huge empty area
- no Android-style dashed line
