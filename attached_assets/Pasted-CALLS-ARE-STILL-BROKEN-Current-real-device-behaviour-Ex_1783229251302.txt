HARD SAFETY FIXES
━━━━━━━━━━━━━━━━━━━━━━

Implement hard runtime guards:

- Before playing remote audio, stop and detach every other audio element except the intended remote audio element.
- If localStream.id === remoteStream.id, block playback.
- If any remote track id equals any local track id, block playback.
- If more than one remote audio element exists, destroy extras.
- If more than one PeerConnection exists for the same matchId, close the older one.
- Stop ringtone/ringback immediately on answer AND before getUserMedia AND before setting remote srcObject AND before audio.play().
- Add a 300ms silent gap between stopping ringtone and opening/playing call audio.
- Never allow local microphone stream to be assigned to an audio element.
