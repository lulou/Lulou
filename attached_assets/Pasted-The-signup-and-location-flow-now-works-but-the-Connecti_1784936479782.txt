The signup and location flow now works, but the Connection DNA algorithm onboarding is missing after signup.

Currently, after the user completes the basic signup/profile information, the app skips the matching-algorithm questionnaire and moves forward without collecting the information needed to personalise Discover.

Restore and properly connect the Connection DNA onboarding flow.

REQUIRED FLOW

The correct order must be:

1. Account created and email verified
2. Basic profile information completed
3. Photos uploaded
4. Connection DNA questionnaire completed
5. Profile review/completion
6. Enter Discover

Do not send a new user directly to Discover before the Connection DNA questionnaire is complete.

CONNECTION DNA PURPOSE

The questionnaire must learn more than basic swipe preferences. It should collect information used to identify genuine compatibility, including:

- personality signals
- relationship values
- communication style
- emotional availability
- connection pace
- affection style
- lifestyle compatibility
- relationship intentions
- green flags
- deal-breakers
- what makes the user feel understood
- what they are genuinely looking for in another person

Use the existing Connection DNA components, questions and database fields already in the project wherever possible. Do not create a completely unrelated questionnaire if this system already exists.

QUESTION EXPERIENCE

Make it feel premium and simple:

- one question or one small group of choices per screen
- clear progress indicator
- large touch-friendly answer cards
- Back and Continue controls
- selected answers visibly highlighted
- smooth transitions
- answers saved as the user progresses
- works properly on iPhone Safari
- user can resume from the last completed question if they leave
- no long technical explanations
- keep Lulou’s cream, rose and charcoal design

Include the previously agreed profile signals such as:

- up to 5 personality signals
- relationship intention / “Ready For”
- green flags
- preferred connection pace
- communication and affection preferences

ALGORITHM DATA

Store the answers in structured fields rather than one unstructured text block.

The matching system should be able to calculate compatibility using categories such as:

- values compatibility
- communication compatibility
- lifestyle compatibility
- emotional compatibility
- relationship-goal compatibility
- connection-pace compatibility

Create or use a normalised compatibility score for internal ranking.

Do not show users a fake percentage unless the score is genuinely calculated from both users’ completed answers.

DISCOVER INTEGRATION

After Connection DNA is complete:

- mark connection_dna_complete = true
- mark onboarding complete only when every required onboarding section is finished
- route the user into Discover
- use the Connection DNA answers in Discover ranking
- still apply hard filters such as gender preference, age, distance, blocks and existing interactions
- use Connection DNA as a ranking signal, not as a replacement for those required filters

Elevated profiles may receive visibility priority, but Elevate must not overwrite compatibility ranking completely.

ROUTING PROTECTION

Add a proper onboarding gate.

On login or refresh:

- incomplete basic profile → return to basic profile step
- missing photos → return to photo step
- incomplete Connection DNA → return to the last unanswered Connection DNA question
- fully completed onboarding → allow Discover

A user must not bypass Connection DNA by refreshing, reopening the app or directly entering /discover.
