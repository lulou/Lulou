1 new like

### CONNECTIONS BADGE

Connections icon count should reflect unread chat activity.

If another user sends me:

1 unread message
→ Connections badge = 1

5 unread messages
→ Connections badge = 5

If two chats contain:

Chat A = 3 unread
Chat B = 2 unread

Connections badge = 5

This should count unread MESSAGES, not just unread conversations, because the intended behaviour is that each new message adds to the count.
