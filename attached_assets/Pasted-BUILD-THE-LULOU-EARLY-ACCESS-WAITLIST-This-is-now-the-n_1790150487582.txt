BUILD THE LULOU EARLY-ACCESS WAITLIST.

This is now the next major Lulou pre-launch feature.

The purpose is to start building a concentrated pool of real users BEFORE the full public launch so Lulou can open smoothly with enough people available in Discover / Intent from day one.

This must feel like a premium dating-product launch — NOT a generic startup email form.

Do NOT interfere with the existing authenticated Lulou app.

==================================================

Launch the waitlist initially around:

The system should still support additional cities later, but Sydney should be the initial launch market.

→ understands what makes Lulou different
→ joins early access
→ confirms email
→ receives waitlist confirmation

→ can invite friends
