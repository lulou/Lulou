Create a premium Lulou launch/loading screen inspired by the minimal loading experience shown in the attached Hinge screenshot.

DO NOT copy Hinge’s logo or exact branding.

Use the same design principle:

- full-screen clean background
- one centered brand mark
- no clutter
- no spinner unless absolutely necessary
- no loading text
- smooth transition into the app

==================================================
1. USE THE REAL LULOU LOGO
==================================================

Use Lulou’s correct existing logo:

the double-L / heart monogram from the current Lulou branding.

Do NOT use:
- a flower
- temporary “L”
- text-only placeholder
- old logo
- generic icon

Use the exact current production logo asset.

==================================================
2. BACKGROUND
==================================================

Use Lulou’s existing warm ivory/off-white background rather than stark bright white if that matches the current app token.

Use the existing app background token so the transition into Lulou feels seamless.

Do not introduce a new background colour.

==================================================
3. CENTERING
==================================================

Place the Lulou monogram visually centered both:

- horizontally
- vertically

Account for iPhone safe areas so it still appears optically centered.

Do not position it relative to the browser chrome.

==================================================
4. LOGO SIZE
==================================================

Keep the logo refined and fairly small.

It should feel similar in visual weight to premium apps:

- clearly visible
- not oversized
- lots of breathing room

Do not place the word “Lulou” underneath unless current branding requires it.

The monogram alone should be enough.

==================================================
5. SUBTLE ANIMATION
==================================================

Add a very subtle launch animation.

For example:

logo opacity:
0 → 1

and/or scale:
0.97 → 1.0

over approximately:

250–450ms

Then remain still.

Do NOT:

- spin the logo
- bounce
- pulse aggressively
- use a progress bar
- use Android-style loading spinner

Keep it calm and premium.

==================================================
6. APP STARTUP FLOW
==================================================

Show this launch screen immediately when the installed Lulou PWA opens.

It should cover the period where Lulou is resolving:

- app bootstrap
- Supabase session restoration
- X-Session-Id/session verification
- onboarding state
- legacy-established state
- initial authenticated app state

Do NOT expose a blank white screen while these checks happen.

==================================================
7. DO NOT HOLD IT LONGER THAN NECESSARY
==================================================

The launch screen should disappear as soon as Lulou has enough state to render the correct route.

Do not introduce an artificial long delay just to show branding.

Expected:

tap Lulou
→ launch screen appears instantly
→ app bootstrap completes
→ smooth fade into correct screen

==================================================
8. SMOOTH TRANSITION
==================================================

When app is ready:

fade the launch screen out cleanly.

Approx:

150–300ms

Do not:

- flash white
- briefly show login before authenticated screen
- briefly show onboarding for established user
- show multiple loaders
- jump layout

The first visible app screen after the logo should be the correct resolved destination.

==================================================
9. BOOT FAILURE HANDLING
==================================================

Do NOT leave the user permanently staring at the Lulou logo if startup genuinely fails.

Use the existing bounded bootstrap/session recovery.

If startup exceeds a sensible timeout:

transition from launch screen into the existing proper recovery/error state.

Do not put technical errors directly onto the splash screen.

==================================================
10. SERVICE WORKER / PWA
==================================================

This must work correctly in the installed iPhone Home Screen PWA.

Audit:

- root mount
- service-worker startup
- stale bundle handling
- chunk-load recovery
- app bootstrap

The loading screen must not mask an infinite startup failure.

==================================================
11. NO DUPLICATE LOADING SCREENS
==================================================

Audit the app for existing:

- page loaders
- full-screen startup spinners
- blank bootstrap states
- onboarding loading blockers

At app startup, there should be ONE authoritative launch experience.

Do not show:

Lulou splash
→ spinner
→ another splash
→ app

It should be:

Lulou splash
→ app

- minimal
- fast
- centered
- restrained
- no Android Material loading UI
- no unnecessary text

The user should feel like they opened a finished native-quality product.
