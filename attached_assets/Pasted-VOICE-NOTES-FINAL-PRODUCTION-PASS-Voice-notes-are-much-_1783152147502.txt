VOICE NOTES FINAL PRODUCTION PASS

Voice notes are much better than before, but they are still not at production quality. I want this feature to behave exactly like a modern messaging app (WhatsApp, iMessage, Telegram, Signal, Messenger). Do not patch around the problems—find the root causes and fix them properly.

1. RESTORE THE MESSAGE COMPOSER
━━━━━━━━━━━━━━━━━━━━━━

The message composer has regressed.

Current behaviour:
• The message input is no longer full width.
• There is a large empty gap before the send button.
• The composer looks compressed compared to before.

Fix:

• Restore the composer to its original full-width layout.
• Restore the original spacing.
• The send button should align exactly as it previously did.
• Recording mode must use this same layout.
• No visual regressions.

2. RECORDING MUST NEVER MOVE THE UI
━━━━━━━━━━━━━━━━━━━━━━

This is currently the biggest UX problem.

When holding the microphone:

• The composer drops downward.
• The conversation starters move.
• The chat layout shifts.
• The whole bottom area jumps.

This is unacceptable.

Required behaviour:

• The composer remains completely fixed.
• Nothing on the screen moves.
• The recording UI morphs inside the existing composer.
• The recording interface replaces the text input without changing the overall height or position.
• Conversation starters never move.
• Chat messages never move.
• Keyboard behaviour remains stable.

The entire bottom section should feel anchored to the screen.

Make recording feel identical to premium messaging apps.
