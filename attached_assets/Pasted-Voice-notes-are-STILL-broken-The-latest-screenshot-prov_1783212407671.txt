- wrong upload URL
- CORS/preflight issue
- Authorization header issue
- iOS Safari XHR blob upload issue
- request body format issue
- backend route not reachable
- Vercel frontend calling wrong backend
- server rejecting multipart/binary request
- response blocked before status is returned
