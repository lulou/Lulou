7. CALL CONNECTION UX

Calls should feel instant.

When a user answers:

• The call should immediately connect.
• No unnecessary delays.
• No confusing transitions.

Microphone permission:

If permission has already been granted previously, the user should NOT see another microphone permission prompt every time they answer a call.

Only request microphone permission when the browser or operating system genuinely requires it.

If the permission prompt is appearing repeatedly because of our implementation, fix the lifecycle so permission is requested once and then reused correctly.

If this behaviour is caused by a platform restriction (for example, Safari requiring user interaction after permission has been revoked), explain that clearly in the report instead of masking it.
