Voice Notes Unlock

Concept:

Introduce a one-time purchase called:

“Voice Notes Unlock”

Purpose:

Allow users to send voice notes in chat permanently after a single purchase.

This is NOT:

a subscription
a recurring payment
a pay-per-message feature
The purchase is permanent for that account.


User Experience

Before purchase:

Voice note icon is visible in chat.
Icon is greyed out.
User can tap it.
User sees:
“Unlock Voice Notes”
After purchase:

Voice note icon becomes active.
User can record and send voice notes.
Access is permanent.

Conversation Experience

Important:

If one user has purchased Voice Notes Unlock:

Both users in that chat should be able to exchange voice notes.

Example:

Tom purchases Voice Notes Unlock.

Tom matches with Sarah.

Tom can send voice notes.

Sarah can also reply with voice notes in that conversation.

Reason:

Voice notes are a conversation tool.

Restricting replies would create an awkward experience.

The feature should unlock voice-note conversations rather than only one-way audio messages.


Business Logic

Voice Notes Unlock is:

Account-level purchase
Permanent entitlement
Never expires
Works with all current matches
Works with all future matches
Not tied to:

individual matches
individual chats
monthly subscriptions
